## Package Overview

This is `netflix`, an R package for scraping and importing Netflix Top 10 viewership data. It provides three methods for acquiring Netflix Top 10 data:
1. **Smart Import** (Recommended): Automatically combines Excel data with web scraping for latest weeks
2. **Excel Import**: Download and process Netflix's official Excel dataset
3. **Web Scraping**: Scrape data directly from Netflix's Tudum Top 10 pages

**Key Feature**: The official Netflix Excel file doesn't always include the current week's data. The `import_netflix_smart()` function automatically detects this and scrapes missing weeks from the website.

## Core Architecture

### Data Sources & Column Normalization
The package handles two data acquisition methods with different column naming conventions:
- **Excel files**: Use `cumulative_weeks_in_top_10`, `weekly_hours_viewed`
- **Scraped data**: Use `weeks_in_top_10`, `hours_viewed`

Both methods normalize to a common schema during data cleaning using `rename_with()` BEFORE type conversion in `mutate()`. This order is critical - always rename columns before attempting to convert their types.

### Main Functions

**R/smart-import.R** (Recommended)
- `import_netflix_smart(file_path, check_latest = TRUE)`: Intelligent data import
  - Downloads Excel file from URL or reads local file
  - Automatically detects if Excel data is missing latest week(s)
  - Scrapes missing weeks from Netflix website to fill gaps
  - Returns combined dataset with all available data
  - Set `check_latest = FALSE` to skip scraping and use Excel only
- `get_latest_netflix_week()`: Determines most recent week available on Netflix website
  - Attempts to parse week selector from Netflix Top 10 page
  - Falls back to calculating last Sunday (Netflix updates weekly on Tuesdays)

**R/import-data.R**
- `import_netflix_excel(file_path)`: Basic Excel import (no auto-update)
  - Accepts local file paths or URLs
  - Downloads Excel files automatically if URL provided
  - Normalizes column names for consistency
  - Handles both date formats and numeric conversions

**R/hello.R**
- Leftover usethis boilerplate (`hello()` stub) — safe to delete.

**R/scrape-data.R**
- `get_netflix_weekly_data(week_date)`: Scrapes single week across 4 categories
  - Categories: Films (English), Films (Non-English), TV (English), TV (Non-English)
  - Base URL: `https://www.netflix.com/tudum/top10`
  - Includes polite 0.5s delay between requests
- `scrape_multiple_weeks(start_date, end_date)`: Batch scraping with weekly intervals
  - Automatically calculates Sunday dates (Netflix week ending)
  - Uses `floor_date()` with `week_start = 7` for Sunday alignment

### Data Processing Pattern
All data functions follow this pipeline:
1. **Acquire**: Download/fetch raw data
2. **Clean**: Apply `clean_names()` from janitor package
3. **Normalize**: Standardize column names across different sources
4. **Type Cast**: Convert dates, integers, numerics explicitly
5. **Safe Handling**: Use conditional checks (`if("col" %in% names(.))`) to avoid errors

## Key Constraints

### R Package Best Practices
- NAMESPACE is auto-generated by roxygen2 - never edit manually
- All exported functions require roxygen2 documentation (`#'`)
- Use `@param`, `@return` tags in function documentation
- Functions without `@export` tag remain internal

### Data Handling Specifics
- Netflix weeks end on Sunday - use `floor_date(week_start = 7)` for alignment
- Excel downloads require `mode = "wb"` on Windows
- Column names vary between data sources - always normalize
- Numeric fields may contain commas in scraped data - use `gsub(",", "", x)`

### Web Scraping Etiquette
- Always include polite delays (`Sys.sleep(0.5)`)
- Wrap scraping in `tryCatch()` for robustness
- Use `message()` for progress updates, `warning()` for skipped items
